# Petsit printable care sheets (Eleventy)

Minimal static site generator that turns one JSON file per dog into a printable, A4-friendly care sheet.

## Requirements
- Node.js 18+ recommended

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Or, equivalently:

```bash
npx @11ty/eleventy --serve
```

## Deploy to GitHub Pages
This repository deploys automatically to GitHub Pages on pushes to `main` using GitHub Actions.

- **Live site**: `https://atarrisse.github.io/Petsit/`
